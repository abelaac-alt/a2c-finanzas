A2C Finanzas 4.0

Incluye:
- Bandeja de pagos pendientes.
- Reglas inteligentes.
- Categorías personalizadas.
- Presupuestos avanzados.
- Notificaciones configurables.
- Aprobaciones de movimientos compartidos.
- Copia JSON, exportación CSV e importación.
- Última conexión visible para administradores.

Instalación:
1. Ejecuta SUPABASE_A2C_CONTROL_FINANCIERO_V40.sql en Supabase.
2. Sustituye app.js en el repositorio web.
3. Actualiza el proyecto Android y compila la APK.
